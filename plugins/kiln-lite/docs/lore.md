# Kiln-Lite lore: who is who, and where the names come from
Names come from Kiln's own history: the v1.5.7 agent roster (2026-04), the CT101 Herdr team (2026-10) and Kiln 4. A name is a reminder of the job; the rules live in the card.

| Name | Role in Kiln-Lite | Origin |
|---|---|---|
| **Kiln** | the operator's session: boss and orchestrator; fires the work, never touches the clay | the plugin itself |
| **Algalon the Observer** | research runner: observe before you cite | v1.5.7 `algalon-the-observer` |
| **Follow-the-Scent** | research workers (Sol, Sonnet), one packet, two noses | v1.5.7 `follow-the-scent` |
| **E Pluribus Unum** | plan runner and architect owner: out of many voices, one plan; rules its council | v1.5.7 `e-pluribus-unum` (the chairman) |
| **The Creator** | architect worker (Opus) | v1.5.7 `the-creator`, the only agent that survived into v3.0.0 |
| **Divergences Converge** | council experts (Astra + Fable, or Sol + Opus), blind round then one exchange | v1.5.7 `divergences-converge` |
| **Mystical Inspiration** | the advisor, Argon: public-only, no vote, spots misses | v1.5.7 `mystical-inspiration` |
| **Critical Thinker** | fresh-builder read of the plan (Sol): buildable from the plan alone? | v1.5.7 `critical-thinker` |
| **Chunk Norris** | build runner, one per milestone; Fred's chunk loop, three strikes | Kiln 4 (Fred's name for the Chunk Master) |
